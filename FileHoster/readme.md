# 📂 FileHoster

A simple **TypeScript + Express** based file server to access your files from any device on the same WiFi.

---

## 🚀 Features

* 📂 View files in a folder
* 📱 Access from phone/laptop (same WiFi)
* 🔗 Click to open/download
* ⚡ Lightweight setup

---

## 📁 Setup

```bash
git clone https://github.com/CodeWithAyaN01/Applications.git
cd Applications/FileHoster
npm install
npm run dev
```

---

## 🌐 Access URL

After starting the server, open:

```
http://localhost:5000
```

👉 From other devices (same WiFi):

```
http://YOUR-IP:5000
```

Example:

```
http://192.168.1.5:5000
```

---

## 📂 Usage

* Put your files inside the `shared/` folder
* Refresh browser to see them

---

## ⚠️ Notes

* `localhost` works only on your laptop
* Use your IP for phone/other devices
* Make sure all devices are on same WiFi
